TURBO KEYSMITH / BITTINGS - HOW TO SHOW THE DEMO ON THIS LAPTOP
================================================================

You do NOT need to install anything or sign in. The demo comes pre-filled
with a sample busy shop (customers, jobs, inventory, receipts, your branding).

----------------------------------------------------------------
BEST WAY - make it look like a real installed app (do this once)
----------------------------------------------------------------
1. Open this "bittings-app" folder.
2. Double-click:  Create Desktop Shortcut.bat   (run it one time)
3. A "Bittings" icon (red keyhole logo) appears on the Desktop.
4. From now on, just double-click that Bittings icon to run the demo.
   It opens in a clean full-screen window - no address bar, no tabs,
   no browser buttons - so it looks like its own program.

----------------------------------------------------------------
EASIEST WAY (no setup - works on almost any laptop)
----------------------------------------------------------------
1. Open this "bittings-app" folder.
2. Double-click:  START-DEMO.html
3. The app opens already full of demo data. That's it.

If your browser asks which app to open it with, choose Google Chrome or Edge.

----------------------------------------------------------------
MOST RELIABLE WAY (use this if anything looks off above)
----------------------------------------------------------------
1. Double-click:  START-DEMO.bat
2. A black window opens (that's the local server - just leave it open).
3. Your browser opens the demo, already full of data.
4. When you're finished, close the black window.

----------------------------------------------------------------
GOOD TO KNOW
----------------------------------------------------------------
- To RESET the demo to a fresh, full shop at any time: re-open START-DEMO.html.
- The laptop should have internet/Wi-Fi during the demo so the dashboard
  charts and PDF receipts display (the app borrows those drawing tools online).
  The rest of the app still works without internet.
- This demo is its own local copy. It does NOT touch or change your real
  live data.
- Best viewed in Google Chrome (or Microsoft Edge).

Questions during setup? Do a full practice run the day BEFORE the meeting.
