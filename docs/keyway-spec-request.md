# What to send for each keyway / lock system (for the master-key calculator)

Photos of the manufacturer manual page or a key-machine spec card are perfect — no need to type anything.
One system per message is easiest (e.g. "Schlage Classic", "Best A2 IC core").

## For every system
1. **Which system:** brand + lock line (e.g. Schlage Classic, Best A2 SFIC, Sargent 6300), the keyway names you use
   (SC1, SC4…) and the key blank numbers (original and Ilco / Kaba numbers if you have them). 5, 6 or 7 pins?
2. **Key cuts:**
   - depth numbers and which end is shallow (0–9? 1–7?)
   - the depth for each number in inches (root depth), or the step between depths
   - first cut position (shoulder to the middle of cut 1) and the space between cuts
   - **MACS** — the biggest jump allowed between two cuts next to each other
   - whether you use 1-step or 2-step progression on it
3. **Pins:**
   - bottom pin length for each number
   - master pin sizes you actually stock (the **smallest** one matters most)
   - top / driver pins: the sizes, and **how you pick the top pin** (a chart, or "the stack must add up to X")
4. **One real example** (names removed): top master, one master key, one change key — and the pins you loaded for that
   lock. The calculator must reproduce it exactly before that system goes live.

## IC cores only (Best / SFIC, large format)
5. The control-key rule — e.g. A2: build-up = control cut + 10 − plug total, every stack = 23. For A3 and A4 we only have
   a magazine article with math errors (stacks 16 and 14): **a Best / dormakaba manual page is what we need most.**
6. Build-up pin sizes, the control key blank, and for large-format cores which chambers are control chambers.
7. One worked core: control key, top master, change key and the pins per chamber (bottom, master, build-up, top).
