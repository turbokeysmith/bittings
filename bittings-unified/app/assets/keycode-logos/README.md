# Keycode portal logos (optional)

Drop a real logo image here and the **Keycodes** list (Home → Vendor tools →
Keycodes) will use it for that make. If a file isn't present, the app falls back
to the site's **favicon**, and if that fails, to the make's **initial letter**.

- **Folder:** `app/assets/keycode-logos/`
- **Format:** PNG (transparent background recommended), roughly square, ~64–128px.
  Displayed at 34×34 on a white rounded chip, so a square mark looks best.
- **Filename = the make's slug** (lowercase), exactly:

| File | Make | Portal |
|---|---|---|
| `toyota.png` | Toyota | techinfo.toyota.com |
| `honda.png` | Honda | techinfo.honda.com |
| `hyundai.png` | Hyundai | hyundaitechinfo.com |
| `nissan.png` | Nissan | nissan-techinfo.com |
| `mazda.png` | Mazda | mazda.locksmithsdrm.com |
| `gm.png` | GM | acdelcotds.com |
| `ford.png` | Ford | motorcraftservice.com |
| `mopar.png` | Chrysler / Jeep / Dodge / Ram (Mopar) | moparkeycode.com |
| `kia.png` | Kia | kiatechinfo.snapon.com |
| `mitsubishi.png` | Mitsubishi | mitsubishitechinfo.com |
| `subaru.png` | Subaru | subaru.locksmithsdrm.com |

No app change is needed after adding files — just drop them in and reload.
