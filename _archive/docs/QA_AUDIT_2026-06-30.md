## ⚠️ The constraint that shapes the functional findings

or Stripe. The real write-paths (inventory move/receive/adjust, POS payments, refund/void,
scheduler status save, D1 file, stock decrement) are **server-side Supabase RPCs** (confirmed:
`inv_move`, `pos_checkout`, `pos_decrement_stock`, `job_set_status`, `set_d1_filed`, …). They
**cannot complete without a live signed-in session + Stripe test keys** (credentials not available
this session). Those backends were instead proven via the Postgres isolation test + the live
function/RLS inventory. True end-to-end binding is in the **Deferred** list.

### 🔴 NEW blocker found + FIXED (with owner approval)
- **All `pay-*` functions returned 503 "tenant service unavailable."** Root cause: `service_role`
  lacked `SELECT` on `shops`/`shop_members`, which `_shared/auth.ts` reads to resolve the caller's
  shop. Phase 5a granted those to `authenticated` only. Fixed via migration
  **`phase5_5c_service_role_tenant_grant`** (`grant select on public.shops, public.shop_members to
  service_role`). Latent until now because the isolation test bypasses the functions' service_role
  path and no card charge had ever run live. **Was a hard go-live blocker.**

### 🟡→✅ NEW finding — FIXED same day (`phase5/5d`)
- **Partial refund mis-recorded as a full refund.** `pay-refund` set `status='refunded'` for any
  refund and there was no `refunded_cents` column, so a partial refund read as fully refunded in
  Transaction History / Closeout and net-collected was wrong. Stripe always refunded the correct
  amount — a **DB/reporting** bug only. **Fixed:** migration `phase5_5d_partial_refund_tracking` adds
  `refunded_cents`; `pay-refund` (v10) accumulates it, blocks over-refund past `captured_cents`,
  allows re-refunding a `partially_refunded` row, and only marks `refunded` when fully refunded (else
  `partially_refunded`); `pay-void` (v8) stamps `refunded_cents = captured_cents`; `index.html`
  Closeout + Transaction History net math = `captured − refunded`. **Verified** in the test shop:
  $40 charge → $15 partial (→ `partially_refunded`, over-refund blocked) → remainder (→ `refunded`).
